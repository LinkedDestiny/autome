本轮只推进 M-02；上一审计关闭 M-01，没有退回缺陷，故无须搬入审计缺陷检查。实现预算 3/30。

## 实现

- `quick.mjs` 抽出同源改动路径读取；`e2e.mjs` 按共享输入、现存 spec、当前证据对应的验收命令选择整套 / 子集 / 不跑。
- 快检相关测试后独立进入浏览器阶段，先准备依赖、内核与 Web build；早先快检失败不阻断此阶段，阶段前置失败则不跑。
- `CI_E2E_BUDGET` 默认 720 秒，旧内核截止按脚本开始 + 600 秒估计，预留 60 秒，剩余不足 240 秒不准入。环境参数校验接受前导零、拒绝非整数及不安全数值。
- 命令保持完整步骤的命令与键，执行后复核键。完整通过才发布 `ran`，子集为 `partial`，预算截断无失败为 `not_run`（含已跑 / 总数），失败为 `failed`。不按退出码猜测截断结果，旧报告先删除；缺失 / 损坏报告不发布通过。
- 命令返回后再次调用原生 `reapRegistered()`；真实清理失败记入报告并拒绝。快检固定报告目录，设置 quick 口径与截止；合并前入口清掉继承的两个口径变量。
- README 说明阶段预算与旧内核 10 分钟假设。原快检测试把 ci-config 子集的过时 12 条断言改成实际 13 条（M-01 新增口径检查后的现状），没有减少检查。
