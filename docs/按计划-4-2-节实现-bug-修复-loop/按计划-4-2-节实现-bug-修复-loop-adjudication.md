### D1-P01（对应 R1-P01）：需求表入口防御与 Bug 控制委托互相冲突

- **主张：** 需求表入口第一行拒绝 Bug 节点，会挡住 Bug 任务的取消、暂停、停止、恢复和 `Requeued` 出队，使 `not_a_bug` 上的取消得到 `Err`。
- **设计位置：** §1 入口防御与转换表末行；风险 R7；M-01 用例 4、12、29。
- **裁决：** 采纳。
- **证据：** `crates/autome-domain/src/task.rs` `apply_with_merge_request` 函数开头先 `match trigger` 处理 `Start/Cancel/Pause/Stop/Resume`，其后才是 `match (state, trigger)` 的节点表；`(Requeued, SlotAvailable)` 在节点表里。防御放在函数第一行，确实先于这些通用处理。控制段只依赖 `awaits_user`、`role()`、`is_enabled`，对 Bug 节点成立。
- **修改落点：** §1：防御移到通用控制段之后、节点表之前，并放行 `(Requeued, SlotAvailable)`（该分支只用 `role()` 与 `is_core_step`）；转换表末行改述为「控制段在防御之前处理，出队分支被防御放行」；R7；M-01 用例 4、12、29 的断言与负向对照（防御放回第一行时失败）。
- **复提计数：** 0。

### D1-P02（对应 R1-P02）：共享门禁复用条件增加「命令相同」会改变需求任务行为

- **主张：** 新增条件会让「配置在两次门禁之间改了命令、且 sha 未变」的需求任务从复用变成重跑，违反 C2。
- **设计位置：** §4 合并前门禁；M-03 范围、用例 `bug_loop_merge_gate_does_not_reuse_a_pass_for_a_different_command`。
- **裁决：** 采纳。
- **证据：** `crates/automed/src/scheduler.rs` `run_gate` 的复用判断只看上一条 `gate.result` 的 `ok` 与 `sha`（约 2110–2124 行），不看命令；设计里「需求任务的命令永远是 `[gate].command`」忽略了配置可在两次门禁之间变化。`gate.result` 事件已记录 `command`，所以新条件可以只对 Bug Loop 生效。
- **修改落点：** §4：「命令相同」只在 `uses_bug_loop` 为真时生效，需求任务与旧 Bug 任务沿用原条件；M-03 范围与该用例（增加需求任务同输入仍复用并发出 `gate.reused` 的断言）、负向对照。旧路径的缺陷不在本任务内处理。
- **复提计数：** 0。

### D1-P03（对应 R1-P03）：直接拒绝工作区 Bug 是未授权的范围缩减

- **主张：** 任务未排除工作区项目，设计却让所有工作区 Bug 在定位前 `Failed{Config}`，把 B-02 当作延期。
- **设计位置：** 非目标；§7 工作区段；M-04 用例 6；Backlog B-02。
- **裁决：** 采纳。
- **证据：** 任务 §4 的范围排除里没有工作区项目；任务 §2 要求 worktree、分支、rebase 等共用部分不变；`scheduler.rs` `working_repos`（约 1403 行）本来就以「已有检出 ∪ 文档 `repos:` 行」确定仓库集合，只是读的是设计文档，Bug Loop 没有它。可以沿用同一机制，不需要新存储。
- **修改落点：**
  - §2：Bug 文档新增可选第六键 `repos`（解析为 `BugDoc.repos`，至多一次），并进入「各轮写什么」表；
  - §7：工作区的仓库选择改读 Bug 文档（没有则读设计文档，覆盖旧 Bug 任务）；定位前没有文档也没有检出时，初始集合为全部成员；`已定位` 时守卫要求 `repos` 非空且是成员名，随后移除未点名、干净且无提交的检出；复现命令在工作区目录执行，命令自己 `cd`；
  - 非目标、M-01（新增 `repos_is_optional_at_most_once_and_read_as_a_name_list`，`bug_doc` 用例 7 → 8，M-01 合计 41 → 42）、M-02（`bug-protocol.md` 说明）、M-04（用例 6 改为工作区仓库选择与修剪）、M-05（新增用例合计 79 → 80）；
  - Backlog B-02 改为「工作区 Bug 完整合并路径的单独 e2e」。
- **复提计数：** 0。
