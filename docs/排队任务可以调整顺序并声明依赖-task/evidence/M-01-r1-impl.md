# M-01 实现轮 #1

范围：设计 §2、§3 与 M-01；仅实现依赖纯函数、store v6 和数据层接口。无上一轮审计退回，故无待搬入的审计回归检查。

## 实现与修复说明

- 新增 `autome_domain::deps`：输入项数上限 8、首次出现顺序去重、自引用/不存在/跨项目/完整路径环检测、可编辑状态表、阻塞原因、满足判定及三种队列重排。
- 可编辑校验先检查 Feature 的实现历史，防止从实现重跑到设计节点后绕过限制。
- 只追加 v6 迁移块，旧迁移不改；新建 `task_after`。旧创建接口委托新事务接口，保留原调用方行为。
- 增加依赖读写、项目依赖图、通知标记、Impl 会话历史、队列位置和重排接口；更新依赖时保留已有边通知值。队列序号溢出返回中文错误并回滚。
- 现有测试仅将设计点名的两处版本断言由 5 改成 6。未改调度、RPC、CLI 或现有 e2e。

69 个全部通过，失败 0、忽略 0；增加来自 12 个 `deps::` 单元用例和 5 个 `deps_store_` 单元用例，原 store 的 52 个全部保留。domain 命令还会启动其它测试目标，但均被过滤为 0，不计入用例数。表内是独立用例总数，重复运行不叠加。

原始日志位于 `.autome/output/m01-baseline-{domain,store}.txt`、`m01-{domain,store}.txt`、`m01-final-{domain,store}.txt`。未运行全量门禁、宿主快检或真实账本上的二进制；store 测试使用原有临时库/内存库。

- 自引用、不存在、跨项目、直接环、三节点环：对应五个独立测试拒绝且验证中文文案/环路径，通过。
- 超过 8 个：9 个不同 id、9 个重复 id 均拒绝；8 个不同 id 接受，通过。
- 去重保序、Done/Cancelled/Draft 目标：lookup 不含状态，因此无状态拒绝路径；测试验证去重、顺序和有效目标接受，通过。
- 全部拒绝文案：10 类错误逐一检查中文与无换行，通过。
- Feature 状态：15 个节点 × Active/Requeued/Paused/Stopped/Failed 五种包装 × 有/无 Impl 历史，另加 Draft/Queued/Done/Cancelled，逐项验证设计 PRE 表，通过。
- Bug 状态：Draft/Queued 接受；Feature 和 Bug 全部节点的五种包装及终态拒绝，通过。
- 阻塞/满足：全部节点包装及四种独立状态逐一验证；只有 Done 满足、只有 Cancelled/Failed 给原因，通过。
- 重排：Top/Before/After、自己作参照、缺失参照、缺失被移动任务，逐项验证且原列表不变，通过。
- v5→v6：降级并删除新表后迁移，旧依赖为空、任务与含 NULL 的队列位置不变，版本 6；再次迁移成功，通过。
- 创建原子性：先插入有效边再遇外键错误，任务、brief、依赖全部回滚；合法创建保留顺序及 brief，通过。
- 替换/清空：相同列表保留标记、增删及重排保留边标记、新边无标记、失败替换保持旧数据、清空删除全部边，通过。

### 2. 失败分支

执行上述自引用、不存在、跨项目、成环、超限、状态拒绝、参照拒绝、创建/替换外键失败、序号溢出测试，全部通过；空依赖是合法输入，清空测试通过。
授权拒绝、读盘失败、超时、外部服务不可达：不适用，本里程碑不新增授权、文件读取、超时或外部服务调用；数据库失败由真实 SQLite 外键错误验证回滚。

### 3. 全部迁移

v5→v6 与重复迁移、既有 v4 迁移回归均通过。依赖边新增→保留重排→删除→清空、失败替换回滚；通知 None/failed/cancelled 的往返；无 Impl→非 Impl→Impl→重跑设计状态均执行通过。队列 Draft 无位置→有位置和 Queued/Requeued 顺序读取均通过。
不新增任务状态机迁移；本轮只对状态做纯判定，已穷举设计规定的全部节点包装和实现历史组合。
