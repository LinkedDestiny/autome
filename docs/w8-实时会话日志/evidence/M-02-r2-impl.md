## 实现与修复说明

- 新增 `server/logtail.ts`，复用事件总线已有订阅/断连扩展点及 M-01 校验、切块函数。路径只从 `session.log` 获取；待查询订阅同步占名额，同会话替换旧对象。
- 每连接最多 4 个订阅；共享轮询定时器；单订阅异步工作合并，读满预算后用 `setImmediate` 继续下一轮，避免等待 500ms。结束标记保持后不再查询状态。
- 先查生命周期再读文件，以本次读取终点判定 final，保证尾行及残缺 UTF-8 最终送出。打开的句柄在 `finally` 关闭；所有异步边界之后检查对象仍有效。退订、断连、替换及关闭使旧结果失效。
- `close()` 注销三个监听器，清除轮询和待续读任务，等待包括旧订阅在内的在途工作完成。独立包装真实文件句柄计数，避免仅凭生产代码自己的 stats 断言释放。
- 首轮 typecheck 发现测试代理的反射调用结果为 unknown（TS18046）；补上读取结果的局部类型后通过。首次超限负向检查在断言失败后因未释放假内核屏障而超时；已把屏障释放加入 afterEach 清理，重跑得到真正的断言失败，非超时判红。
- 实现提交：`625e902`。未修改依赖、已有测试、协议、内核或其它 worktree。

### 2. 失败分支

- invalid、limit、not_found、offline、kernel 各有实际拒绝断言（02–04、10、12），并检查资源/调用次数。
- 读盘失败：分别注入 open 的 EACCES、stat/read 的 EIO（18），断言中文 error 消息和实际句柄归零；删除、截短、路径变化见 08–09。
- 内核查询超时作为 call 抛错检查，初始化映射 kernel（10）；跟随期间调用失败继续读文件，恢复后正常结束（14）。本层不新增超时计时器，超时由内核调用层返回。
- 空文件：运行中不结束、历史空文件 ended（07）；残缺输入见 17。
- 拒绝授权不适用：M-02 不新增身份认证或网络入口，沿用事件总线扩展点；路径白名单拒绝已检查。其它外部服务不可达不适用，本层唯一外部调用为内核，offline 已检查。

### 3. 全部迁移

- 无订阅 → 校验拒绝（02）、额度拒绝（04）、待查询占名额（04）。
- 待查询 → 跟随（01）、历史读取（07）、内核拒绝（03/10）；待查询 → 替换（04）、断连（11）。
- 跟随 → 追加并保持（01/05）、暂缺文件等待 → 文件出现（09）、查询失败保持 → 恢复结束（14）。
- 跟随/历史读取 → ended（06/07/17）、rotated（08）、deleted（09）、error（18），每个终态均检查订阅/句柄/定时器释放。
- 跟随 → 退订（12）、断连（11）；读取中 → 退订/断连/替换（19）、关闭（13），旧结果全部丢弃。
- 多轮历史读取保持 ended 标记、预算耗尽立即续读，最终结束（20）；UTF-8 残缺保持 → 补齐或会话结束（17）。
- 断连 → 新连接带 next 续传（15）；关闭 → 后续订阅忽略、重复关闭（13）。
- 定时器无 → 第一个订阅有 → 最后订阅结束无（21）；500ms 读增量，1000ms 查询生命周期；同订阅并发 flush 不重入（19）。
- 上行 subscribe/unsubscribe 和下行 chunk/end/rejected 均经真实 eventbus + 假传输执行，已有 22 条事件总线测试不退化。
