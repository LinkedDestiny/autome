# M-01 实现 #1 验收证据

结论：M-01 验收通过，提交独立审计；实现轮为 1/25。本轮无上一轮审计退回项。

## 改动与判据

- `eventbus-protocol.ts` 导出日志上下行类型、订阅/退订白名单解析、内核路径校验；保留通用解析器的扩展透传行为。
- `logtail-chunk.ts` 按 UTF-8 标量或最大非法前缀扫描，累计 JSON 转义后的文本字节和完整信封字节（包括变化的 offset/next 位数），超限前输出当前块。相较设计原先的比例缩短方案，此实现直接累计精确编码成本，避免反复解码，同时保留相同外部契约。
- UTF-8 的 E0/ED/F0/F4 第二字节范围受约束；只有合法未完成前缀等待下一次读取，非法前缀立即替换。原始字节消费与替换后文本长度分离。
- 自审发现 JavaScript 正则 `$` 可匹配末尾换行前的位置，ID 实现采用真正的输入终点断言，测试加入末尾 LF、CRLF、TAB。

### 2. 失败分支

全部消息非法分支（信封、type、未知字段、ID、offset）及内核路径拒绝均已执行，见协议 3–8。空输入、非法 UTF-8、残缺尾部见切块 1/5/6。拒绝授权、读盘失败、超时、外部服务不可达不适用：M-01 仅纯函数，不调用内核、不打开文件、不连接外部服务；服务端拒绝与读取错误映射属于 M-02。

### 3. 全部迁移

本轮无持久状态机。两种上行类型的合法/非法路径、三种下行编码均覆盖；UTF-8 完整→输出、残缺且非 final→保留、残缺且 final→替换并消费、保留后补齐→连续输出、非法→立即替换均已实跑。订阅/连接生命周期不适用，属于 M-02/M-04。

### 4. 域边界

已执行 ID 空/1/128/129、全部禁用字符及末尾换行；offset 缺省/0/1/最大安全整数/超界/非有限/前导零字符串；路径绝对性与规范化边界；空/单标量输入、2–4 字节 UTF-8 各残缺长度、JSON 转义与大信封。日期、闰日和跨年不适用：本函数无日期输入。
