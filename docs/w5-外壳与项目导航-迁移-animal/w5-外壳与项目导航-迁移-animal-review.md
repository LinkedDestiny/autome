## 问题

### R1-P01：内核恢复后，离线首屏的根数据没有重新加载路径

- 类别：第 2 类「内部逻辑矛盾」。优先级：P1。
- 违反的要求与设计条款：任务 R-01（项目及计数）、R-02（所有项目的待处理和进行中任务卡）、R-03（任意项目和任务跳转）；设计第 180、184 行的 loader 失败结果与重验路径，第 234–237 行的恢复后横幅/写判定，以及第 275、287 行依赖根数据的首页和候选列表。
- 根因：设计把连接状态恢复与根 loader 数据恢复分开处理，却只有账本事件和 W3 的 `reload` 能触发后者。`core: connected` 本身不会触发任何重验。
- 具体反例：项目中已有一个 `stopped` 任务，事件总线已追平账本；在内核暂时离线时打开首页，根 loader 按设计返回 `kernel.ok=false`、空项目和任务。WebSocket 收到首次 `hello(core=offline)`，随后内核恢复，收到 `core(connected)`，期间没有新的任务账本事件。按设计，横幅消失、写入口恢复；首页仍显示「内核离线，暂时拿不到任务」，项目栏和 ⌘K 仍为空，直到额外事件或重新导航/刷新。已有任务并未消失，但三个入口均无法呈现它。
- 源码证据：`apps/web/app/lib/live.tsx:20–22` 中 `onCore` 仅为 `setCore`，重验只在 `onEvents`、`onReload`；`apps/web/app/lib/live-client.ts:54–63,83` 的首次 hello 和 core 消息不调用 `onReload`；`apps/web/server/eventbus.ts:119–125` 恢复时广播 core 并拉账本，而第 81–93 行在没有新事件时不会产生额外通知。
- 最小实验：直接调用当前 `createLiveClient`，依次注入上述 hello 和 core 消息，实际得到 `reload=0`、`events=0`、`core=[offline,connected]`、`connections=[connecting,open]`，退出码 0。原始输出：`.autome/output/review-1-recovery-probe.txt`。这是对现有回调链的实际验证；未声称完成拟建 W5 页面或浏览器验收。
- 检查范围与同类位置：根 loader 失败/恢复、首次 hello、后续 core 消息、事件总线恢复路径，以及共用根数据的项目栏、首页、⌘K；这些表现属于同一个根因，不拆成多个问题。
- 建议修改：在任务允许修改的 Web 层明确「离线加载失败后收到 connected」的根 loader 重验路径，同时处理恢复发生在首次 hello 的情况。可在 `live.tsx` 内使用现有重验机制，不改变 W3 的 `live-client.ts`、`live-routes.ts` 或服务端协议语义。对应验证应能在没有新账本事件的情况下恢复已有项目和任务。这是缺失的数据恢复行为，不是单纯要求增加测试。

### R1-P02：⌘K 按 slug 搜索与根 loader 的字段白名单不能同时满足

- 类别：第 2 类「内部逻辑矛盾」。优先级：P2。
- 违反的设计条款：设计第 283 行要求 `filterCandidates` 按 slug 匹配；第 182 行及 M-04 `shell-data` 第 5 条（第 421 行）却限定任务输出只含 `id, kind, title, project_id, state, fix_round?`；第 287 行又限定候选来自根 loader、不另发请求。对应任务范围为 R-03，但 R-03 本身没有强制 slug 搜索。
- 根因与反例：唯一候选数据源删除了筛选所需的字段。例如 `id=T-12`、标题「登录页修复」、`slug=login-fix`、项目名「演示项目」，输入 `login-fix` 按筛选条款应命中，但白名单结果没有任何字段包含该值。slug 不能从标题或 ID 可靠推导。
- 源码证据：`crates/automed/src/dispatch.rs:554–557` 分别输出 id、kind、slug、title，slug 是独立字段；问题发生在设计规定的 Web 投影阶段。
- 检查范围与同类位置：总体任务投影、M-04 字段断言、M-05 候选来源及过滤规则。其他已承诺的过滤字段 ID、标题、项目名均有来源；确定缺失的是 slug。
- 建议修改：优先删除任务未要求的 slug 搜索承诺；若保留，则把 slug 纳入根 loader 的字段白名单，并同步 M-04 第 5 条断言。两种选择都无需新增请求或扩大到 W6/W7。
