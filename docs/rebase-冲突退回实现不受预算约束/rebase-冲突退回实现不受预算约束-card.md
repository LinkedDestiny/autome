## 还缺的部分（本任务）

2. **同一冲突反复出现不熔断**：连续 N 次 rebase 冲突且冲突文件集相同（会话没有让冲突消失），应停下等人，而不是继续退回。可参考 T-28 门禁熔断的做法（同节点、同指纹、连续计数，用户 rerun/extend 后从零数）。
