## 标待审之前的自审清单

### 1. 情形表逐行

- 类型：明确类型遵用户；现有行为异常→bug；新增/改变→feature；混合或未知→追问不默认。逐条阅读技能第 1 步，并通过自审「类型混合或未知先问」。
- feature：背景、要做什么、验收标准必填；不做什么、参考可选写无。bug：现象、复现步骤、期望、实际、环境必填，线索可选写无。自审模板与追问断言通过；K1–K19 实跑两类合法/非法正文。
- 项目：指定项目匹配、未指定选最深物理路径、移除项目过滤、无法匹配列候选、空列表停止、显式 id 创建；T8、自审空列表通过，V1/V2/V4 实证列表、跨目录和不存在项目。
- 确认：完整正文+类型+项目+待开始+大小；模糊/局部/附修改不创建；修改回到完整展示。T2/T3 与拒绝修改自审通过；五种立即开始说法由 T4 检查。
- 回显：排队优先且无开始命令；draft 显示开始命令但不执行；started true 显示已开始；其它原样转达。T4 逐条检查，V2/V3 实跑 draft/active。无面板不显示链接、健康面板首页/详情由 P1–P10 复验。

### 2. 失败分支

- 未安装 CLI：T7 检查 command -v、两条安装原文；审阅第 2 步止步且不代安装。
- 拒绝/模糊确认、含修改回复：T2 和自审拒绝修改分支；未真实启动 Agent，对话行为仅为文本契约证据。
- 写文件能力缺失：自审确认停止并交给用户，不回退 shell 正文；读盘/权限等其它命令失败按原文+退出码停止，由自审其它失败覆盖。
- 项目不存在/移除：V4 实跑不存在项目；移除及目录推断失败文本分支回第 3 步。列表为空自审通过。
- 空正文、超长：K15、K10、V5 实跑；非法 UTF-8 的错误处理规则由自审检查，不声称 check-card 会检测所有编码问题。
- 用法退出 2：自审停止、不改参数重试；成功缺 task.id：自审不重试、建议 ls 核对；其它错误：原文转达后停止。
- 超时/外部不可达：P8 超时、P1/P7 不可达、P9 HTTP 错误均实跑，面板探测失败不影响创建结果。

逐条检查技能流程：信息不足→追问→重新检查；类型未知→先定类型；CLI 缺失→停止；项目不匹配→选择→确认、空列表→停止；校验不合格→修正/追问→重验；未确认→等待、修改→重新完整展示、确认→创建；创建失败→按原因返回项目/正文或停止，任何重试→重新确认；成功→排队/draft/active/原样未知四分支→可选面板→清理临时正文。上述静态检查通过；CLI 与脚本路径按前述用例实际执行。拒绝授权、修改后确认等真实多轮宿主交互仍属 H-01/H-02，未声称实跑。
