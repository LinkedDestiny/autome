# T5 评估覆盖矩阵

角色（AT1–AT4）× 协议不变量（cycle-runner 融合协议），每个 T5 场景登记其确定性低成本替代。真实拉起用例按覆盖缺口选取。

> **替代性质标注（避免以文本存在充当行为遵从证据）**：
> - **行为替代**：确定性地代理了 agent 的*运行时行为*（如 dry-run 即时返回代理「启动即结束」）。
> - **文本/模板替代**：只验证生成任务文件*含某条协议文本*（模板完整性），**不等于** agent 会遵守。
>   对无行为替代者，必须标注「仅 T5 可验证行为」，日常门禁不声称覆盖其行为。

| 角色 | 协议不变量 | T5 场景 | 确定性替代 | 替代性质 |
|---|---|---|---|---|
| AT1 | 形成全部结论前不读裁决记录与旧评审（独立性） | `reviewer-independence/` | 任务文件 AT1 含「不读取裁决记录、旧版评审内容」条文（T1 模板 oracle 断言其存在）；review 每轮覆盖写的路径正确 | **文本/模板替代**——仅 T5 可验证「是否真的不读」这一行为 |
| AT4 | 复验验收命令而非信任 `待审`；实现缺陷退回 `开放` 计 reopen | `auditor-rerun/` | 验收命令本身确定性可复跑（`run-gates.sh` T1–T3 全绿即证明门禁存在且有判别力）；任务文件 AT4 含「不得信任里程碑状态、独立复验」条文 | **文本/模板替代**——仅 T5 可验证审计轮「是否真的复验」这一行为 |
| AT1–AT4 | 每轮结束「启动即结束」不等待 | `launch-and-return/` | `t2_launch.sh`/`t3_relay.sh`：启动脚本 `--dry-run` 即时返回 0、非 dry-run 后台拉起后台 pid 存活即返回（证明脚本层不阻塞） | **行为替代**——dry-run/后台返回确定性代理「启动即返回」的脚本行为；agent 是否「不再自行连续启动」仍需 T5 |
| AT2 | 裁决记录 append-only、复提计数与争议项冻结 | （未单列 T5，按覆盖缺口暂不拉起） | 任务文件 AT2 含 append-only 与复提条文（模板 oracle） | **文本/模板替代**——如需行为验证再补 T5 场景 |
| AT3 | 不得标记 `已完成`；`待审` 必附验收命令结果与证据 | 由 `auditor-rerun/` 间接覆盖（审计复验即检验 AT3 的 `待审` 质量） | 任务文件 AT3 含「不得标记已完成」条文（模板 oracle） | **文本/模板替代** + 门禁存在性 |
| AT4 | 验证缺口就地加强复验，不退回实现轮 | （未单列 T5，按覆盖缺口暂不拉起） | 任务文件 AT4 含实现缺陷/验证缺口二分条文（模板 oracle） | **文本/模板替代**——如需行为验证再补 T5 场景 |

## 选取策略（成本受控）

- 真实拉起优先覆盖「仅 T5 可验证行为」的行×列（AT1 独立性、AT4 复验）——它们无行为替代，是覆盖缺口。
- 「启动即结束」有脚本层行为替代，T5 只需低频抽样确认 agent 编排层不违反（不重复启动）。
- 运行必须带 `--max-cost-usd` 与 `--ablation with-without`（见 `README.md`），禁止进入每轮门禁集。
