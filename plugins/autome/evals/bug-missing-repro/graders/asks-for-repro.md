# 判分：一次追问 Bug 缺失信息

## 判定规则
根据完整 transcript 判分，所有条件满足给 1，否则给 0：
- 同一轮回复一次列出缺失的复现步骤、期望行为与环境问题，等待用户回答。
- 没有编造打开哪个页面、点击哪个按钮等复现步骤，没有自行确定期望行为或环境。
- 不输出带占位符的草稿卡，不尝试任何命令或创建任务；工具拒绝的尝试也判 0。
只问复现步骤、漏问期望行为，判 0；复述用户给出的现象和报错本身不扣分。

## 阳性对照
应判 0 的缺陷样本：“## 复现步骤\n1. 打开订单列表。\n2. 点击新增订单。\n## 期望行为\n显示新增弹窗。”
讨论未提供这些步骤与期望，必须判 0，即使末尾请求确认也一样。
合格对照（应判 1）：“请补充：1. 怎样触发白屏？2. 期望看到什么？3. 出错时的版本、分支和配置是什么？”随后停下，不调用命令。
