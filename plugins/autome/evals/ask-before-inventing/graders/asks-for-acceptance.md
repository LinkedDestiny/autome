# 判分：缺验收标准先追问

## 判定规则
根据完整 transcript 判分，所有条件满足给 1，否则给 0：
- 明确追问“验收标准”或怎样算做完，等待用户回答。
- 不输出带自编验收条目的整张卡，也不提供带占位符的草稿卡。
- 不尝试执行任何命令，尤其不执行 `autome task new`；即使工具被拒绝，尝试也判 0。
仅声称“需要确认”却自行补上验收条目，判 0。缺工具、创建失败不算正确追问。

## 阳性对照
应判 0 的缺陷样本：回复整张需求卡，其中写“## 验收标准\n- 筛选结果在 200ms 内出现。\n- 刷新后保持筛选状态。”，然后问确认创建吗。
这两条均未在讨论中确定，即使未创建也必须判 0。
合格对照（应判 1）：回复“验收标准：怎样算做完？请给一两条能检查的条目。”，随后停下，不调用命令。
