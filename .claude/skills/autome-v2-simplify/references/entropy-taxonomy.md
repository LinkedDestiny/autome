# 九类熵：定义、搜索方法、反例

来源：Yevanchen/reclaim-code-entropy 的九类候选与 deepseek-harness `dsh-find-simplifications` 的
强候选清单，合并去重。熵 = 没有当前理由的维护面。每类都附「不是这个」，因为**重复与有意的独立是两回事**。

| # | 类别 | 长什么样 | 怎么找 | 不是这个 |
|---|---|---|---|---|
| 1 | 未消费的面 | 没有生产消费者的导出、API、配置键、事件、包、CLI 参数、接缝方法 | 对每个公开名穷尽 grep（符号、字符串、路径）；命中按生产 / 非生产 / 模糊分级 | 为 out-of-tree 实现留的接缝（仓库文档写明的）；公开包的对外 API；刚加还没接上调用方的代码 |
| 2 | 镜像事实 | 同一事实两个表示：两处默认值、缓存与源并存、布尔标志 + 状态枚举、手抄的 RPC 表 | 找「X 与 Y 必须同步」的注释、同名常量、两份表的一致性测试 | 比较**独立产生、可能分歧的观测**的不变量（这是检测，不是镜像） |
| 3 | 投机泛化 | 只有一个实现的接口、只传过一个值的参数、多会话 / 后台任务表 / 中途转向等没人用的能力 | 找接口的实现数、参数的调用点取值集合、feature flag 常年一个值 | 仓库文档明确保留的扩展点；给外部实现的插件契约 |
| 4 | 多余的路由或层 | 只转发的 wrapper、到同一行为的两条路径、纯粹再导出的 barrel、一函数一文件 | 看函数体是否只是 `return inner(...)`；看两条路径是否落到同一实现 | 兼容门面（供外部或测试导入，文档写明）；跨进程边界的适配 |
| 5 | 生命周期重复 | 多套就绪 / 取消 / 清理 / 停止标志指向同一所有者；sentinel + promise + flag 三重表示 | 对每个标志与 promise 画「谁拥有、谁置位、谁读」；找出映射到同一所有者的 | rollback、回调隔离、终态仲裁、worker 所有权、dispose-to-quiescence 的机制——它们看着重复但各管一段 |
| 6 | 错位的防御 | 进程内、已经有类型的交接处再做校验、再拷贝一份；对自己刚构造的值做 null 检查 | 对每个校验 / 拷贝问：值从哪来、下一个所有者是谁；来源是本进程可信构造就是候选 | 信任边界（用户输入、网络、文件、跨租户）上的校验，不管多冗余都保留 |
| 7 | 手搓基础设施 | 平台或已装依赖已经提供的东西自己又写了一份：重试、LRU、路径处理、时间格式化 | 对照标准库与 lockfile 里已装的包 | 仓库依赖预算明文拒绝的 SDK；为了可测性用本地 fake 替代的窄客户端 |
| 8 | 支持性残留 | 只为测试或脚本存在的包、只被测试引用的导出、过时的 fixture、文档里的死链接 | 消费者分级后只剩非生产命中的 | 回归基线（probe、golden 文件）是**测试基础设施**，其消费者本来就是测试 |
| 9 | 加了又弃的残留 | 半途放弃的 feature：一半的 UI、注册了没人发的事件、迁移了但没读的列 | `git log` 找引入提交，看后续是否有完成的迹象；找 TODO / FIXME 的年龄 | 分阶段交付中、文档或计划里写明「下一阶段接上」的 |

## 搜索纪律

- 一次搜索不够。同一个名字要搜：符号、字符串字面量（`"name"`、`'name'`）、路径片段、配置键、
  环境变量名、序列化字段名、wire 方法名、CLI flag。
- 生产代码最大的增量优先。从最近几次大提交的新增文件开始，比从「未用导出」清单开始命中率高。
- 按域并行派子代理时每个域一个，回来必须带 `file:line` 证据，而不是「看起来没用」。
- 静态找不到调用者 ≠ 没有调用者。反射、注册表、按名分发、模板、CI 脚本都要查（档案 §0.8）。

## 太薄的候选

拼写错误、跑一次 `knip` 的原始输出、「这看起来很复杂」——这些不构成候选。
真的小到不值一条记录的，改成一条带标签的行内 TODO，说明为什么安全、哪一步能简化它。
